# Full-Stack Engineering Agent Skill

A unified agent skill combining senior frontend/UI/UX and backend engineering guidance.

## Focus

### Frontend
React, TypeScript, Vite, shadcn/ui, Tailwind CSS, Motion for React,
React Hook Form, Zod, TanStack Query, responsive design, accessibility,
frontend performance, and reusable component architecture.

### Backend
NestJS, MongoDB/Mongoose, Zod, JWT, Argon2id, secure verification/reset
tokens, Nodemailer/SMTP, Pino, Swagger, security, testing, observability,
and backend performance.

### Full Stack
Shared validation, API contracts, end-to-end auth flows, testing,
security reviews, performance reviews, CI, documentation, and production readiness.

Copy the `full-stack-engineering` directory into your project's `skills/`
directory or the location used by your coding agent.
